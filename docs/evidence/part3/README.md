# Smart-X Part 3 — Measured evidence index

This directory contains **only actual observed results**, not sample outputs.

## P3-11 telemetry benchmarking

Run the committed `scripts/verify_part3_telemetry_load.py` against a freshly
started *local* .NET Development API for each size, following
`docs/part3/LOAD_VERIFICATION.md`.

- `telemetry-10k.json` — genuine 10,000-reading Float base series plus smaller
  typed series; complete accepted/indexed checks and narrow/broad GET timings.
- `telemetry-50k.json` — genuine 50,000-reading Float base series with the
  same typed controls and measurement method.

**These named JSON files are not pre-generated by this commit.** They must be
created by a successful live run on the developer's machine and reviewed
before staging; no invented durations, sensor IDs, or pass summaries belong
here.

The script refuses remote destinations and refuses overwriting existing
results. Generated telemetry uses unique local test identifiers; the evidence
still includes those UUIDs and local environment metadata, so review each
artifact for disclosure suitability before pushing.

Future P3-11 commits will add graph scaling, frontend regression, Docker and
full validation evidence. Screenshots and CI output should be genuine captures
with enough context for independent reproduction.
